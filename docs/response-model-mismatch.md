# 响应模型核验已移除

2026-10-28 用户明确要求删除该功能。自 v0.1.10 起移除核验实现、原始响应/流式回调、请求关联和响应缓冲，以及管理接口和界面。不会因上游声明模型不同或缺失而替换生成响应。

旧 `response_model_mismatch` YAML 仅为升级启动兼容而接受，加载时记录警告后忽略，可由管理员删除；任何旧开关、动作或映射均不能恢复功能。`POST /v1/response-model/validate` 返回 404，capabilities、配置元数据和 health 不再暴露核验字段。外部管理端需要同步移除入口和调用。

已发布 v0.1.9 二进制仍包含旧实现。需要升级至 v0.1.10；不能通过关闭旧版开关获得等价的资源开销改善。发布与产物验证见 [v0.1.10 记录](v0.1.10-release.md)。

本文件保留用于兼容历史链接，不再提供启用教程。原因、验收和升级边界见 [移除记录](response-verification-removal.md)，外部管理端适配见 [Helper 交接](claude-uniform-ttl-helper-handoff.md)。
